# ADR-003: News Repository And Cache

## Status

Accepted

## Context

Новостная фича работает с сетью, JSON, файловым кэшем и изображениями. Если вся эта логика находится в SwiftUI-экране, код становится сложно поддерживать и тестировать.

## Decision

Используем цепочку:

`NewsListView -> NewsViewModel -> NewsRepository -> NYTimesNewsService / CachedNewsStore`

Дополнительно:

- `NewsLoading` отделяет `NewsViewModel` от конкретной реализации репозитория
- `NewsDTOMapper` отвечает за преобразование JSON в display-модели
- `NewsImageCacheStore` отвечает за кэширование изображений
- `NYTimesAPIConfig` читает ключ из `NYTIMES_API_KEY`
- `CachedNewsStore` принимает `cacheFileURL`, чтобы кэш можно было тестировать в изолированной временной директории
- `NewsDemoData` показывает демо-новости, если API-ключ не задан и локального кэша еще нет

## Consequences

Экран новостей занимается только отображением состояния. Репозиторий скрывает детали источника данных: сеть или кэш.

Кэш повышает устойчивость приложения: если сеть недоступна, пользователь может увидеть сохраненные новости.
Демо-режим делает приложение пригодным для показа без секретного API-ключа.

`NewsViewModel` получает `NewsLoading` через initializer, поэтому состояния загрузки можно тестировать без реальной сети и файловой системы.
