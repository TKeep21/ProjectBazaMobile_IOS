# ADR-005: Task Search, Filters And Analytics

## Status

Accepted

## Context

Для проекта нужна дополнительная фича, сопоставимая с остальными экранами приложения. При этом важно не переносить бизнес-логику в SwiftUI-экран, потому что критерии оценки отдельно смотрят на качество кода и тестируемость.

## Decision

Добавлена фича расширенного управления задачами:

- поиск по названию и описанию
- фильтры: все, активные, готовые, просроченные, важные
- сортировка: по созданию, приоритету, дедлайну
- статистика: всего, активные, готовые, просроченные, важные, процент выполнения

Логика вынесена в отдельные типы:

- `TaskListQuery`
- `TaskFilter`
- `TaskSortOption`
- `TaskAnalytics`

`TaskListView` хранит выбранные параметры и отображает результат, но не содержит самих правил фильтрации и подсчета.

## Consequences

Фича легко демонстрируется на защите и проверяется unit-тестами. Добавление новых фильтров или сортировок не требует переписывать весь экран задач.

Ограничение: состояние фильтра и поиска пока не сохраняется между запусками приложения. Для текущей цели это не критично.
