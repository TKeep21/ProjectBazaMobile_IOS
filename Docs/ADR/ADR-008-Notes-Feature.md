# ADR-008: Notes Feature

## Status

Accepted

## Context

В Android-версии проекта есть заметки, поэтому iOS-версия должна иметь сопоставимую фичу, чтобы платформы выглядели согласованно на защите. При этом заметки не должны быть просто SwiftUI-экраном с локальным состоянием.

## Decision

Добавлена отдельная фича `Notes`:

- `Note`, `NoteDraft`, `NoteValidationError`, `NoteStore`, `NoteListQuery`, `NoteFileStore` находятся в `HWmobileCore`
- `NoteManager` связывает core-логику с SwiftUI
- `NoteListView` показывает список, поиск и удаление заметок
- `NoteEditorView` отвечает за создание и редактирование

Заметки сохраняются в `Application Support/notes.json`. Пустые заметки не сохраняются. Если заголовок не задан, он формируется из первой строки текста заметки.

## Consequences

Фича заметок имеет отдельную модель, core-логику, persistence, экран и тесты. Это делает ее сопоставимой с остальными частями приложения и помогает закрыть критерий дополнительного функционала.
