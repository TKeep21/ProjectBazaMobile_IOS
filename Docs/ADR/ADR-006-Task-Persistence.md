# ADR-006: Task Persistence

## Status

Accepted

## Context

До этого задачи хранились только в памяти. Для мобильного приложения это слабое место: пользователь создает задачу, перезапускает приложение и теряет данные.

## Decision

Добавлен `TaskFileStore`, который сохраняет массив `Task` в JSON-файл в Application Support.

`TaskManager` загружает сохраненные задачи при старте и сохраняет изменения после создания, удаления, замены или переключения completion-state.

## Consequences

Задачи переживают перезапуск приложения. Логика хранения отделена от SwiftUI-экранов и покрыта unit-тестами.

Ограничение: хранение сделано через JSON-файл, а не базу данных. Для текущего объема проекта это проще, прозрачнее и достаточно надежно.
